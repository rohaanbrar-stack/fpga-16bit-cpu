## What this is

Not a softcore port and not a RISC-V implementation — the point is to **design** the instruction set and the datapath, then build them. A single-cycle 16-bit RISC-like CPU with a small hand-designed ISA, running hand-assembled programs on a Digilent Basys 3.

Learning FPGA design from zero. Every phase has a gate that must pass before the next one starts, so nothing gets built on an unproven layer.

Design decisions locked so far: **single-cycle first** (pipelining is explicitly out of scope), **Harvard memory model** on block RAM, ~16–25 opcodes in R/I/J formats.

## Phase 0 — Blink

The point of Phase 0 isn't the LED. It's proving the entire path *Verilog → synthesis → implementation → bitstream → JTAG → running hardware* before any real design is built on top of it.

```verilog
module LED_Blink(
    input clk,
    output led
);
    reg [25:0] count;

    assign led = count[25];

    always @(posedge clk) begin
        count <= count + 1;
    end
endmodule
```

A free-running 26-bit counter with one bit wired to an LED. No comparator, no reset — a high-order counter bit is already a divided clock.

**Why bit 25:** each bit of a free-running counter toggles half as often as the one below it, so bit *N* toggles at `100 MHz / 2^(N+1)`. Bit 25 gives `100e6 / 2^26` = **1.49 Hz** — an unmistakably visible blink.

Constraints used (uncommented from the Digilent master):

```tcl
set_property -dict { PACKAGE_PIN W5  IOSTANDARD LVCMOS33 } [get_ports clk]
create_clock -add -name sys_clk_pin -period 10.00 -waveform {0 5} [get_ports clk]
set_property -dict { PACKAGE_PIN U16 IOSTANDARD LVCMOS33 } [get_ports led]
```

> **Note:** the master XDC assumes a 16-bit vector port `led[0]`. This design uses a scalar `led`, so the index and braces are dropped. A mismatch here fails implementation with "no ports matched."

**Gate met** — bitstream generated clean, programmed over JTAG, LD0 blinking at 1.49 Hz.

## Building

1. Open Vivado, create an RTL project targeting **XC7A35T-1CPG236C** (select the part directly — Vivado ships no Basys 3 board files).
2. Add the design source from `phase0-blink/` and the constraints file from `constraints/`.
3. Run Synthesis → Implementation → Generate Bitstream.
4. Connect the Basys 3 by micro-USB (**data cable**, not charge-only), set the mode jumper to **JTAG**, power on.
5. Hardware Manager → Open Target → Auto Connect → Program Device.

JTAG configuration is volatile — power-cycling clears the FPGA. Program the onboard QSPI flash instead if the design should survive a reboot.
